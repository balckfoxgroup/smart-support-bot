# Black Fox VPN — 用户指南（简体中文）

> 技术词保留英文：License、Server、Panel、VPN、Installer、Update、Configuration、SSH、WireGuard。UI 为英文 Title Case。

## 1. 介绍
运维型 Installer：在您的 VPS 上部署 WireGuard + 3X-UI Panel。不是消费级 VPN 客户端。

## 2. 功能
见 `AI_Knowledge_Base_ZH.md`。要点：Basic 免费三项；Exit/Node 最多各 6；Pro ≠ AI Pro；Configure Panel 只修已有 Exit/Node。

## 3. 安装
1. 从 foxnext.net 下载 Setup。2. 安装。3. 选语言。4. 选 Basic/Pro/AI Pro。5. 进入主界面。

## 4. 使用
Central Server Setup → Connect SSH → Full Deploy → Panel Login Info → 需要时 Registration 激活后 Add Exit → Configure Panel。

## 5. 页面
Operations、Check System、View、Settings、Registration、Contact（另有 Domain/Mesh）。

## 6. 新手
Basic · Central 选 IR/CN/RU · 先 SSH 再 Deploy · Exit 前先 License · 网络受限用 Proxy Settings。

## 7. 进阶
Tunnel → Exit → Configure Panel → Node → Domain → CDN → Mesh → Bot。  
AI：BFXA + quota，用 Tasks 并确认。链路：WireGuard / GRE / Stealth-WSS。

## 8–9. 排错
看 status/terminal → Proxy → Registration/配额 → Check System → @HiBlackFoxVpn + Device ID。

Delete History 仅本地；Reset All Servers 清除远程 WG/Panel 但保留 SSH；Factory Reset 为高风险 Pro 操作。

## 10. 关联
共用 Store · 切换模式不丢服务器 · 删 hop 影响链路完整性。
