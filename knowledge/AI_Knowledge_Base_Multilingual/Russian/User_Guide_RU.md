# Black Fox VPN — руководство пользователя (русский)

> Термины: License, Server, Panel, VPN, Installer, Update, Configuration, SSH, WireGuard — на английском. UI — Title Case English.

## 1. Введение
Операционный Installer для развёртывания WireGuard + 3X-UI Panel на вашем VPS. Не потребительский VPN-клиент.

## 2. Возможности
См. `AI_Knowledge_Base_RU.md`. Важно: без License в Basic только Setup Central / Connect SSH / Full Deploy; макс. 6 Exit и 6 Node; Pro ≠ AI Pro.

## 3. Установка
1. Скачайте Setup с foxnext.net. 2. Установите. 3. Язык. 4. Режим Basic/Pro/AI Pro. 5. Главное окно.

## 4. Использование
Central Server Setup → Connect SSH → Full Deploy → Panel Login Info → при необходимости Registration и Exit → Configure Panel.

## 5. Страницы
Operations, Check System, View, Settings, Registration, Contact (+ Domain/Mesh overlays).

## 6. Новичок
Basic · централь IR/CN/RU · SSH до Deploy · License до Exit · Proxy при блокировках.

## 7. Профи
Tunnel → Exit → Configure Panel → Node → Domain → CDN → Mesh → Bot.  
AI: BFXA + quota, Tasks, подтверждение. Линки: WireGuard / GRE / Stealth-WSS.

## 8–9. Проблемы
SSH/Deploy/AI/License — смотрите terminal, Proxy, Registration, Check System, затем @HiBlackFoxVpn + Device ID.

Delete History = локально; Reset All Servers = снимает WG/panel удалённо, SSH остаётся; Factory Reset — опасная Pro-операция.

## 10. Связи
Один store · смена режима не стирает серверы · удаление hop влияет на цепочку.
