# Black Fox VPN Installer & Android — Product Map

Support knowledge for Ask AI when the product catalog is thin. Do not invent software versions.

## Official name
Always use: **Black Fox VPN Installer & Android**

## What this product is
Black Fox VPN Installer & Android manages VPN infrastructure on a Linux VPS over SSH. It is not a consumer browse VPN client. Core work is 3X-UI panel + WireGuard automation.

## Main areas
- Operations: Connect SSH, Full Deploy, Exit/Node/Tunnel, Domain, CDN, Configure Panel
- Check System: health checks
- View: Topology and link status
- Settings: app settings and Factory Reset
- Registration: Pro / AI Pro license activation
- Contact: creator contact

## Suggested Central setup order
1. Registration if Pro / AI Pro is needed
2. Central Server Setup (Host, Port, User, password/key)
3. Connect SSH
4. Full Deploy (3X-UI Sanaei + WireGuard)
5. Panel Login Info
6. Configure Panel when inbound/outbound/relay is needed
7. Add Exit / Node / Tunnel as required
8. Domain / CDN if public access is needed
9. Mesh / Topology for monitoring

## Frequent modules
- Connect SSH: open/test SSH to the saved central server
- Full Deploy: one-shot install of panel + WireGuard
- Configure Panel: inbound/outbound/relay; may auto-activate Free Domain on sub-configs when quota remains
- Panel Login Info: show panel URL/user/password/token
- Exit / Node / Tunnel: scale the mesh (max 6 exit/node slots)
- Domain / CDN / Free Domain / External Proxy: see `vpn-installer-domain-mesh` (Free Domain: Pro=3, AI Pro=5 per install)
- Mesh / Topology: Mesh Servers view + Deploy / Repair Link Monitor Agents
- Terminal / Status Bar: remote commands and long-op feedback
- Factory Reset: destructive local reset — confirm carefully

## Modes
- Basic: free core (Setup Central, Connect SSH, Full Deploy); Free Domain quota = 0
- Pro / AI Pro: advanced features per license; Free Domain 3 / 5; prices only from license catalog
