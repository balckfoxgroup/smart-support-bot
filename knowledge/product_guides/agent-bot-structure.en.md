# Smart Support Bot — Product Map

Ask AI knowledge for **Smart Support Bot** only (`@BlackFox_Agent_Bot`). Do not invent Installer or Config Builder details from this file.

## What it is
A Telegram support assistant — not a VPN client and not a 3X-UI panel. Users open a product catalog; Ask AI answers within that catalog.

## Main capabilities (catalog teaching keys)
- Ask AI design goal — free-form Q&A only inside the same product
- Product catalogs — JSON features, howto, and photos per product
- Product knowledge isolation — no cross-catalog leakage
- Group and topics — community support and multilingual education
- Nightly config — scheduled free gift to the channel
- Social news — posts from approved sources
- Stats and user list — operational visibility for admins
- Admin settings — central control of agents, catalogs, message targets
- Multilingual (FA/EN/RU/ZH) — one bot for four languages
- Local answer memory — learning without tying to one cloud API
- Catalog teaching photos — screenshots only when truly needed
- Main menu structure — short path product → Ask AI
- Human support handoff — when evidence is insufficient
- Conversation analysis — improve catalogs from real user questions

## What it does not do
- SSH onto customer servers
- Full Deploy from Telegram
- Mixing other products’ knowledge in one Ask AI session
